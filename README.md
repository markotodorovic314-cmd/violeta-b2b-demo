# Violeta B2B Portal — interactive demo

Interactive concept for a Violeta customer and administration portal. The prototype demonstrates:

- account-specific product catalog, prices, discounts and warehouse availability;
- cart, checkout, quick order and repeat-order flows;
- PDF, spreadsheet, XML, CSV, TXT and image order intake with review of unknown items;
- order status tracking, invoices and delivery documents;
- customer, credit-limit, price-list and stock administration;
- ERP/WMS integration status and order approval workflow;
- responsive partner and admin views.

All prices, customers, stock levels and transactions are illustrative demo data. The final ERP name, endpoints and business rules will be configured after technical discovery.

The static site is served from `dist/`.
